# Clinic Management SaaS Landing Page

Create a modern, premium, animated landing page for a Clinic Management Application using:

- Angular
- TailwindCSS
- Anime.js

The design should feel:
- modern
- medical-tech
- premium SaaS
- clean
- highly responsive
- smooth and interactive

## Design Style

Use a combination of:
- glassmorphism
- soft gradients
- smooth shadows
- rounded corners
- subtle grid backgrounds
- animated blobs
- elegant motion

Color palette:
- Primary: #2563eb
- Secondary: #0f172a
- Accent: #06b6d4
- Background: dark with gradient sections
- Text: clean white / slate hierarchy

Typography:
- bold hero typography
- large section titles
- modern spacing
- professional healthcare feel

## Use Anime.js For

Add smooth animations for:
- hero content entrance
- floating dashboard cards
- counters/statistics
- staggered feature reveals
- navbar transitions
- hover interactions
- CTA button glow/pulse
- scroll-triggered animations
- background floating particles/blobs

Animations must be:
- smooth
- premium
- performant
- not excessive

# Technical Requirements

## Angular Structure

Use clean Angular architecture:
- reusable standalone components
- feature-based structure
- clean separation of sections

Suggested structure:

/components
/navbar
/hero
/features
/analytics
/pricing
/testimonials
/faq
/footer

Use:
- signals if useful
- modern Angular syntax
- optimized rendering

## TailwindCSS

Use:
- responsive utilities
- modern spacing
- gradients
- glass effects
- grid layouts
- container sizing
- reusable utility patterns

The design must be fully responsive:
- mobile
- tablet
- desktop
- ultra-wide

Generate:
